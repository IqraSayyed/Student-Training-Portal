# 🎓 Student Training Portal

A responsive and interactive **Student Training Portal** built using **HTML, CSS, and JavaScript**. The application allows users to register and manage students, search and filter records, switch between light and dark themes, and explore live data fetched from a public API.

## 🌐 Live Demo

[View the Live Website](https://iqrasayyed.github.io/Student-Training-Portal/)

## ✨ Features

- 📱 Fully responsive design for desktop, tablet, and mobile
- 👨‍🎓 Register new students with form validation
- ✏️ Edit existing student details
- 🗑️ Delete registered students
- 🔍 Search students by name
- 🎯 Filter students by course
- 🔢 Display total number of students dynamically
- 💾 Store student records using Local Storage
- 🌙 Dark and Light theme with saved user preference
- 🌐 Fetch and display user data from a public API
- 🧭 Smooth navigation between different sections
